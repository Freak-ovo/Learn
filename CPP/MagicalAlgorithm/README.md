## 自学算法构建库函数利用cpp实现

### 步骤 1：明确 C++ 算法库的定位与技术选型
 1. 定位与场景
    C++ 适合构建高性能、泛型化、底层可控的算法库，需明确：
    用途：是学习用（侧重可读性）、竞赛用（侧重效率），还是工业级（侧重鲁棒性 / 可复用）？
    泛型支持：是否需要适配任意数据类型（如支持int/float/ 自定义类的排序）？
    依赖约束：是否依赖 STL（可参考 STL 但避免直接复用核心逻辑，如需自研则完全独立）？
 2. 技术选型
    标准版本：选择 C++17/C++20（支持constexpr、概念（Concepts）、范围（Ranges）等特性，提升泛型安全性）；
    内存管理：优先用 RAII（智能指针unique_ptr/shared_ptr、容器），避免裸指针泄漏；
    构建工具：CMake（跨平台编译）+ Ninja（加速构建）；
    测试工具：Google Test（GTest）+ Google Benchmark（性能测试）；
    文档工具：Doxygen（自动生成 API 文档）。
