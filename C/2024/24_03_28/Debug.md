# 调试Debug
## 一、调试基本步骤
 - 发现程序错误存在
 - 用隔离、消除等方法对错误进行定位
 - 确定错误产生的原因
 - 提出纠错的解决方法
 - 对程序错误予以改正，重写测试
  
## 二、 Debug 与 Release
 - Debug
   - 调试模式
     - 包含调试信息，并且不作任何优化，便于程序员调试程序。
 - Release
   - 发布版本
     - 已经优化完毕，程序在代码和运行速度上面是最优的，以便用户很好地使用。
  
## 三、环境准备
  - 常用快捷键
    - F5
        启动调试
    - F9
        设置断点：程序停止处
    - F10
        逐过程，通常用来处理一个过程，可以是一条语句也可以是一次函数。
    - F11
        逐语句，可以进入函数内部
    - CTRL + F5
        开始执行不调试，直接使用程序
